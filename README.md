# Smart LED Control using ESP8266 (IoT Project)

This project demonstrates how to control an LED remotely using Wi-Fi and a mobile application.
It uses ESP8266 microcontroller and Blynk IoT platform to enable real-time control.

## Components Used
- ESP8266 (NodeMCU)
- LED
- 220Ω Resistor
- Breadboard & Jumper Wires

## Software Used
- Arduino IDE  
- Blynk IoT App  

## Working
ESP8266 connects to Wi-Fi and receives commands from Blynk cloud.
When button is pressed in the app, LED turns ON/OFF.
